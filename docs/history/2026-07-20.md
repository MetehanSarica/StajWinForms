# Proje İnceleme Raporu — 2026-07-20

Otobüs bileti satış sistemi (StajWinForms + StajWinForms_API + StajWeb) genel kod incelemesi ve geliştirilebilir alanlar.

## Yüksek Öncelik

1. **MD5 şifre hash'i** — `StajWinForms_API/Helpers/Md5Helper.cs`. MD5 kırılmış bir algoritma; parolalar veritabanında MD5 ile saklanıyor. PBKDF2/BCrypt + salt'a geçilmeli.
2. **Düz metin API anahtarı** — `staj-2026-gizli-anahtar` hem `StajWinForms_API/appsettings.json:2` hem `StajWinForms/appsettings.json:2` içinde, ayrıca `StajWeb/Program.cs:8` içinde hardcoded. Statik API key yerine JWT token daha uygun; geliştirmede User Secrets kullanılabilir.
3. **Loglama hiç yok** — API'de `ILogger` kullanılmıyor, WinForms tarafında hiç log yok; hata ayıklama ve audit imkânsız. Serilog eklenebilir.

## Orta Öncelik

4. **~35+ `async void` event handler** — `LoginForm.cs:16`, `MusteriKaydi.cs:97`, `CokluMusteriKaydi.cs:72` vb. Exception'lar kaybolabiliyor; try/catch'li ortak bir async pattern gerekli.
5. **`GetAwaiter().GetResult()` deadlock riski** — `FirmaBrowserForm.cs:50` (BackgroundWorker içinde senkron bekleme). Task tabanlı async'e geçilmeli.
6. **Form kodlarında tekrar** — `OtobusBrowserForm`, `FirmaBrowserForm`, `KaptanBrowserForm` aynı CRUD + grid yükleme desenini kopyalıyor. Ayrıca `BiletSorgula.cs:31` ve `BiletIptal.cs:31` aynı API çağrısını tekrarlıyor. Ortak bir `ApiService` katmanı çok kod azaltır.
7. **API tarafında validation yok** — `CreateBiletDto`, `SatinAlDto` gibi DTO'larda `[Required]`/`[MaxLength]` eksik; sadece client-side kontrol var.
8. **Global exception middleware yok** — `BiletlerController.cs:178-181` gibi yerlerde `catch { return StatusCode(500) }` ile exception detayı kayboluyor.
9. **Genel exception yakalama, log yok** — `MusteriKaydi.cs:46-56`, `BiletSorgula.cs:36-43`, `SeferDetay.cs:58-65` sadece MessageBox gösteriyor.

## Düşük Öncelik

10. **Magic string'ler** — yetki kontrolü `"btnOtobusBrowser"` gibi string'lerle yapılıyor (`OtobusBrowserForm.cs:22` vb.) → enum/sabit kullanılmalı.
11. **Olası N+1 sorgu** — `SeferDetayController.cs:53` ve `60-64` civarı collection navigation; `.Include()`/projection ile çözülebilir.
12. **Test projesi yok** — `tmp_crashtest` manuel deneme projesi, silinebilir; yerine xUnit/NUnit ile `AuthController`, `BiletlerController` testleri yazılabilir.
13. **Hardcoded URL** — `StajWeb/Program.cs:8` içinde `http://localhost:8081/`; `IConfiguration`'dan okunmalı.
14. **DTO tekrarı** — WinForms, Web ve API aynı DTO sınıflarını ayrı ayrı tanımlıyor; ortak bir sınıf kütüphanesine taşınabilir.
15. **TC kimlik doğrulaması basit** — `Dogrulama.cs:5-9` minimal; TC check-digit algoritması eklenebilir.
